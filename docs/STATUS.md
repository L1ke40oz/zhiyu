- 尚未配置真实 LLM、embedding 与视觉服务。`.env` 已建立为空配置，用户可自行填写；本地 OCR 不依赖服务商。
- 尚未部署到 VPS；域名已确认，服务器连接、面板版本与资源参数未提供。本机没有可用的 Docker 命令，因此没有声称镜像已构建通过。
- 需要在实际 HTTPS 手机环境验证陀螺仪、摄像头、麦克风权限、音频与多人现场体验。当前客户端保留原项目的备用输入。
- 联网搜索、SSE 流式回答、PPTX 原生解析和简答评分尚未实现。
- 知识点可改名、卡点可关联与标记解决；知识点合并、拖动分组和考试范围细选尚未实现。
- 当前计划按简单间隔和优先顺序安排；没有训练或宣称个性化遗忘概率。
- 没有登录和跨设备同步。派对房间是临时内存状态，课程与学习记录是持久化状态。
