## 当前边界

### 2026-10-25 课程资料外框上传修复

- 线上已复现：课程资料页的外框点击选文件／拖入文件后没有上传请求，而「上传资料」弹窗内上传正常。
- 原因为 `onFinished?.(await send(files))`：未传可选回调时，上传调用也被短路。改为先执行上传，再通知可选回调；共读页的直接拖入入口一并恢复。
- 生产构建（含类型检查）与现有 44 项测试通过。浏览器仅在独立诊断会话中临时加载修复后的前端构建，使用真实线上接口验证：课程外框点击、外框拖入、弹窗上传、共读页拖入的约 587KB PPTX 均成功并解析为 ready，页面无控制台错误。诊断课程和测试资料已删除。
- 修复需用户在 VPS 拉取代码并重建应用后才会对正式访客生效；这次验证没有修改 VPS 文件或 OpenResty 配置。

- 用户已确认线上配置了视觉模型；本地配置与线上独立，自动化验证使用模拟模型与 Tavily 服务。此次新增能力仍需用户更新 VPS 后验证真实厂商连接；本地 OCR 不依赖服务商。
- 用户已在 VPS 部署，线上 HTTPS 健康接口返回 200；已确认 1Panel OpenResty 容器使用 host 网络。服务器连接、面板版本与资源参数未提供，本机没有可用的 Docker 命令；不据此声称已在本机验证 Linux 镜像。
- 需要在实际 HTTPS 手机环境验证陀螺仪、摄像头、麦克风权限、音频与多人现场体验。当前客户端保留原项目的备用输入。
- SSE 流式回答和简答评分尚未实现。联网搜索与 PPTX 原生提取已接入。
- 知识点可改名、卡点可关联与标记解决；知识点合并、拖动分组和考试范围细选尚未实现。
- 当前计划按简单间隔和优先顺序安排；没有训练或宣称个性化遗忘概率。
- 没有登录和跨设备同步。派对房间是临时内存状态，课程与学习记录是持久化状态。
